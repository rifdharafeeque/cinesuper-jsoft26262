## Project Description

CineSuper is a mini OTT movie library website built using HTML, CSS, JavaScript, and Supabase.

Users can browse movies, search for movies, filter them by genre and language, view movie details, see ratings and reviews, and submit their own reviews.

## Features

- Movie library with posters
- Search movies by title
- Filter movies by genre
- Filter movies by language
- Movie details popup
- Director information
- Movie ratings
- User reviews
- Add new reviews
- Supabase database integration
- Responsive dark theme
- Purple theme colour
